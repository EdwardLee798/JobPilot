# 对话式简历生成功能使用指南

## 功能概述

JobPilot 现在提供两种简历输入方式：
1. **📄 上传简历** - 适合已有简历文件的用户
2. **💬 对话生成** - 通过智能对话创建简历，适合没有简历的用户

## 对话生成功能特点

- 🤖 **智能对话** - AI助手通过对话引导收集信息
- 📊 **实时进度** - 可视化进度条显示完成度
- 💡 **智能提问** - 根据缺失信息动态生成问题
- 📝 **灵活输入** - 支持文字描述或上传相关文档
- ✨ **自动整合** - 自动合并和结构化信息

## 使用步骤

### 1. 启动对话模式

1. 打开 JobPilot：http://localhost:5000
2. 进入「简历解析」标签页
3. 点击 **💬 对话生成** 按钮
4. 智能助手自动启动并提出第一个问题

### 2. 回答问题

**初始问题示例**：
```
你好！我是智能简历助手，我会通过对话帮你生成一份完整的简历。
首先，请简单介绍一下你自己：姓名、目前身份（学生/在职）、联系方式（邮箱、手机），
以及你期望的职位方向是什么？
```

**回答方式**：
- 在输入框中输入你的回答
- 按 `Enter` 键或点击「发送」按钮

**示例回答**：
```
我叫张三，目前是某大学计算机专业的研究生。
邮箱：zhangsan@example.com
手机：138xxxx8888
期望职位：Python后端开发工程师
```

### 3. 逐步补充信息

助手会根据你的回答提出下一个问题，例如：

```
很好！接下来请详细介绍你的教育背景：
- 本科/硕士学校名称
- 专业
- GPA或主要成绩
- 毕业时间
```

你可以：
- **详细描述**：用文字描述你的经历
- **简要概括**：只提供关键信息
- **跳过**：暂时跳过某些问题（助手会稍后再问）

### 4. 查看进度

对话框下方的进度条实时显示完成度：
- **0-30%**：基本信息阶段
- **30-60%**：教育和经历阶段
- **60-80%**：技能和补充信息
- **80-100%**：信息完整，可以生成

当进度达到 **80%** 时，「完成生成」按钮会自动出现。

### 5. 完成生成

1. 当助手提示信息已基本完整时
2. 点击「完成生成」按钮
3. 确认对话框
4. 等待简历生成完成

生成的简历会自动出现在「已解析的简历」列表中。

### 6. 其他操作

**重新开始**：
- 点击「重新开始」按钮
- 清空所有对话内容
- 重新开始收集信息

**切换模式**：
- 随时可以切换回「上传简历」模式
- 对话内容会保留，直到完成生成或重置

## 对话技巧

### 提供详细信息

**好的示例**：
```
我在2020-2022年在阿里巴巴实习，担任Java开发实习生。
主要负责订单系统的微服务开发，使用Spring Cloud、MySQL、Redis等技术。
主要成果包括：
1. 优化订单查询接口，响应时间降低40%
2. 开发订单状态通知模块，服务10万+日活用户
3. 参与系统重构，提升代码可维护性
```

**不够详细的示例**：
```
在阿里巴巴实习过，做Java开发。
```

### 结构化回答

使用清晰的结构，助手更容易理解：

```

- 本科：清华大学，计算机科学与技术，2016-2020，GPA 3.8/4.0
- 硕士：北京大学，软件工程，2020-2023，GPA 3.9/4.0

算法设计、数据库系统、分布式系统、机器学习

获得奖项：
- 国家奖学金（2019）
- ACM-ICPC亚洲区域赛银奖（2018）
```

### 逐步补充

不需要一次性提供所有信息：

**第一轮**：
```
我叫李四，北京大学硕士，软件工程专业。
```

**第二轮**（助手会追问）：
```

```

## API 架构

### 后端API

**启动会话**：
```
POST /api/resume/interactive/start
Response: {
  "success": true,
  "session_id": "uuid",
  "question": "初始问题"
}
```

**发送消息**：
```
POST /api/resume/interactive/chat
Body: {
  "session_id": "uuid",
  "text": "用户输入"
}
Response: {
  "success": true,
  "assistant_reply": "助手回复",
  "is_complete": false,
  "completion_percentage": 45,
  "missing_fields": {...}
}
```

**完成生成**：
```
POST /api/resume/interactive/finalize
Body: {
  "session_id": "uuid"
}
Response: {
  "success": true,
  "resume_id": "uuid",
  "message": "简历生成成功！"
}
```

**重置会话**：
```
POST /api/resume/interactive/reset
Body: {
  "session_id": "uuid"
}
```

### 技术实现

**核心模块**：`backend/modules/resume_parser/interactive_builder.py`

**关键函数**：
- `init_empty_profile()` - 初始化空简历模板
- `aggregate_profile()` - 聚合用户输入到简历JSON
- `process_user_input()` - 处理单轮对话
- `finalize_resume()` - 完成简历生成

**LLM集成**：
- 模型：Qwen Plus (通义千问)
- 功能：信息抽取、字段补全、问题生成
- 温度：0.2（确保一致性）

## 数据流程

```
用户输入 → interactive_builder.process_user_input()
         → aggregate_profile() 调用LLM
         → 更新简历JSON
         → 生成下一个问题
         → 返回给前端

完成生成 → finalize_resume()
         → 保存为 {resume_id}.json
         → 显示在已解析列表
```

## 常见问题

### Q1: 对话中可以上传文件吗？

目前版本主要支持文字输入。未来版本会支持在对话中上传PDF、DOCX等文档。

### Q2: 可以修改已输入的信息吗？

可以！只需在后续对话中重新提供信息，助手会自动更新。
例如：
```
用户：我之前说的手机号错了，应该是 139xxxx9999
助手：好的，已更新你的手机号码。
```

### Q3: 对话会保存多久？

会话在浏览器关闭或手动重置前一直保存。建议在一次对话中完成简历生成。

### Q4: 可以跳过某些问题吗？

可以。助手会根据必填和选填字段调整问题。但必填信息（姓名、联系方式、教育背景）需要完整提供。

### Q5: 生成的简历格式是什么？

生成的是结构化JSON格式，与上传简历解析结果相同。可以用于：
- 简历优化
- 自动投递
- 导出PDF（待实现）

## 优化建议

### 用户体验

1. **分段输入**：
   - 不要一次性输入大量文字
   - 按助手的问题分段回答
   - 便于信息准确提取

2. **使用关键词**：
   - 技能：列出具体的技术栈
   - 经历：突出成果和数据
   - 证书：完整名称和时间

3. **及时确认**：
   - 检查助手理解是否正确
   - 发现错误及时纠正

### 系统优化

**未来改进方向**：
1. 支持文件上传（实时解析并融入对话）
2. 语音输入
3. 简历预览（实时查看生成效果）
4. 多语言支持
5. 简历模板选择
