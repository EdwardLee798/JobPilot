================================================================================
  🚀 AUTOMATED JOB APPLICATION SYSTEM - QUICK START
================================================================================

WHAT THIS DOES:
  Automatically applies to jobs on Boss Zhipin and Liepin platforms using
  your resume data, with AI-powered personalized greetings.

================================================================================
  📋 3-STEP QUICK START
================================================================================

STEP 1: Check System
  $ ./check_setup.sh

STEP 2: Configure
  $ ./quick_setup.sh

STEP 3: Run
  $ ./auto_start.sh

That's it! The system will:
  ✓ Start the application
  ✓ Open browser for login
  ✓ Wait for you to login
  ✓ Automatically start applying to jobs

================================================================================
  🎮 CONTROL COMMANDS
================================================================================

  START:
    ./auto_start.sh                    Full automation
    ./gradlew bootRun                  Manual start

  CONFIGURE:
    ./quick_setup.sh                   Guided setup
    python3 config_from_json.py        Update from resume
    ./update_config.sh                 Interactive config

  CONTROL:
    ./stop.sh                          Stop everything
    ./check_setup.sh                   Verify setup

  MONITOR:
    tail -f logs/app.log               View logs

================================================================================
  ⚠️  IMPORTANT NOTES
================================================================================

  1. Platforms: Boss Zhipin (150/day limit), Liepin (unlimited)
  2. AI is optional: Works without API key (uses default greetings)
  3. Login required: Must login via WeChat QR code first time
  4. Cookies saved: Subsequent runs auto-login from saved cookies
  5. Be responsible: Respect platform limits and terms of service

================================================================================
  🆘 TROUBLESHOOTING
================================================================================

  PROBLEM: Java not found
  SOLUTION: brew install openjdk@21

  PROBLEM: Port 8888 in use
  SOLUTION: ./stop.sh && sleep 5 && ./auto_start.sh

  PROBLEM: No jobs found
  SOLUTION: python3 config_from_json.py

  PROBLEM: Database locked
  SOLUTION: ./stop.sh && sleep 5 && ./auto_start.sh
